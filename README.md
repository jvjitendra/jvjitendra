### 02 · TaskFlow — Full-Stack Task Manager
**A task-management application built around authenticated, user-owned data.**

TaskFlow explores the fundamentals of a complete web application: identity, protected endpoints, relational data, task workflows, and a separate frontend/backend architecture.

- Registration and login with JWT-based authentication
- CRUD operations and user-specific task ownership
- Status, priority, search, and filtering workflows
- SQLAlchemy data access with PostgreSQL for production configuration and SQLite for local development
- Pytest-based testing and a Docker/CI-oriented project setup

**Built with:** Python · Flask · REST APIs · SQLAlchemy · PostgreSQL · SQLite · Pytest

[Repository](https://github.com/jvjitendra/task-manager) · [Project site](https://task-manager-frontend-tau-lemon.vercel.app)
